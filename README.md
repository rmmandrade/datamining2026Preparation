# ACDC Customer Segmentation

Data Mining — Deliverable 1, Group 07.

This project explores ACDC's coworking membership data, integrates external business-demography statistics and provides an interactive EDA dashboard.

## Project structure

| Path | Contents |
|---|---|
| `notebook/` | Project notebooks, numbered in execution order |
| `data/raw/` | Original ACDC dataset and external Eurostat CSV |
| `data/processed/` | Prepared dashboard data generated by notebook 03 |
| `dashboard/` | Standalone dashboard application and its assets |
| `docs/` | Supporting documentation and dashboard screenshots |
| `tools/` | Supporting scripts, including `build_dash_notebook.py` |
| `requirements.txt` | Python dependencies required to run the notebooks and dashboard |

## Data

Place both input files in `data/raw/`, keeping these filenames:

- `acdc_dataset.csv`
- `eurostat_business_demography_pt_2021_2023.csv`

## Notebook order

Read or execute the notebooks in the following order, running code cells from top to bottom:

1. `01_business_understanding.ipynb` — Business context and project objectives.
2. `02_data_understanding.ipynb` — EDA, data-quality assessment and external data integration.
3. `03_dash_features.ipynb` — Data cleaning and feature preparation for the dashboard.
4. `04_dash_app.ipynb` — Interactive EDA dashboard.

Keep the notebooks inside `notebook/` and use that directory as the notebook working directory so relative paths resolve correctly.

Notebook 03 generates `data/processed/acdc_dash.parquet`, which is required by notebook 04 and the standalone application in `dashboard/app.py`.

Include the supplied `dashboard/`, `docs/` and `tools/` folders with the project. Running the notebooks does not recreate the standalone dashboard code, assets, screenshots or helper scripts. Notebook 03 creates `data/processed/` and `docs/` if needed and writes the processed data and dashboard data dictionary.

## Requirements

Install the dependencies listed in `requirements.txt` before running the notebooks. Select the Python environment containing those dependencies as the notebook kernel.
